# Robust Fruit Quality Classification

> A reproducible PyTorch research workflow for postharvest fruit-quality classification under class imbalance and simulated environmental variation.

This project fine-tunes **DenseNet121** to classify fruit images into three commercial-quality grades: **Good**, **Bad**, and **Mixed**. It compares a standard baseline with two imbalance-aware training strategies, then evaluates each model on clean and perturbed images.

## Highlights

| Area | What the project provides |
| --- | --- |
| **Modeling** | Transfer learning with ImageNet-pretrained DenseNet121 |
| **Imbalance study** | Baseline, minority augmentation + weighted sampling, and class-weighted loss |
| **Evaluation** | Per-class metrics, prediction exports, confusion matrices, bootstrap confidence intervals, and McNemar comparisons |
| **Robustness** | Controlled brightness, contrast, noise, and blur perturbation tests |
| **Reproducibility** | YAML configuration, deterministic seeding, automated dataset audit, scripts, and unit tests |

## Results at a glance

The experiments use a 19,526-image, three-class fruit dataset with a clean test split of 1,953 images. Values below are the committed experiment outputs; they should be interpreted in the context of this dataset and configuration.

| Experiment | Accuracy | Balanced accuracy | Macro F1 | Mixed-class F1 | Training time |
| --- | ---: | ---: | ---: | ---: | ---: |
| Baseline | **99.59%** | **99.77%** | **0.9956** | **0.9953** | 30.0 min |
| Augmentation + sampling | 99.44% | 99.58% | 0.9943 | **0.9953** | 20.1 min |
| Class-weighted loss | 99.23% | 99.23% | 0.9864 | 0.9725 | **11.0 min** |

On clean images, all three approaches achieve strong results. The value of the augmentation-and-sampling strategy appears most clearly during noisy input conditions: it retains **90.73%** accuracy under Gaussian noise, versus **74.71%** for the baseline.

## Experimental design

The training configuration is centralized in [`configs/config.yaml`](configs/config.yaml). The current study uses 224 × 224 inputs, a batch size of 64, mixed-precision training where available, a fixed seed of 42, and macro F1 for checkpoint selection.

| Experiment | Imbalance treatment | Purpose |
| --- | --- | --- |
| `baseline` | None | Establish a transfer-learning reference point |
| `augmentation` | Conservative minority-class augmentation and `WeightedRandomSampler` | Improve representation of the underrepresented Mixed class |
| `class_weighted` | Balanced weights in `CrossEntropyLoss` | Penalize minority-class errors without resampling |

The robustness benchmark applies controlled brightness shifts, contrast shifts, Gaussian noise, and Gaussian blur to the test images. This separates clean-test performance from resilience to plausible image-quality variation.

## Quick start

### 1. Create an environment

Python 3.10–3.12 is supported. An NVIDIA GPU is recommended for training, but the project can run on CPU.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

For a CUDA-enabled PyTorch build, install the appropriate PyTorch wheel for your system before installing the remaining requirements. See the official PyTorch installation selector for the correct command.

### 2. Supply the dataset

Place the image dataset in `Processed Images_Fruits/`, or update `dataset.root_dir` in [`configs/config.yaml`](configs/config.yaml). The raw image data, trained model weights, and checkpoints are intentionally excluded from version control.

### 3. Verify the installation

```powershell
python -m pytest -v tests
python scripts/audit_dataset.py
```

## Run experiments

The entry point runs the dataset audit first, then orchestrates training, evaluation, robustness checks, and result comparison.

```powershell
# Run every experiment and generate reports
python main.py --experiment all

# Run a single experiment
python main.py --experiment baseline
python main.py --experiment augmentation
python main.py --experiment class_weighted

# Audit data only
python main.py --audit-only

# Evaluate existing checkpoints without retraining
python main.py --evaluate-only
```

Useful overrides:

```powershell
python main.py --experiment augmentation --epochs 10 --batch-size 32 --seed 7
python main.py --experiment all --skip-robustness
python main.py --experiment baseline --no-resume
```

## Reproducibility notes

- The default seed is `42`; it can be changed with `--seed` or in the YAML configuration.
- The dataset manifest is versioned as `fruit_quality_dataset_manifest.csv` to make split and class assignments auditable.
- Checkpoints (`*.pth`) and raw images are ignored to keep the repository lightweight. Recreate them by running the relevant experiment.
- Reported results are generated from the supplied configuration and should be revalidated when changing the dataset, split, hardware, dependencies, or hyperparameters.
